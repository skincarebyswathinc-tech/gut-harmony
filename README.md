# Gut Harmony

Build a modern web application called "Gut Intelligence Platform".

Purpose:

A digital health platform that analyzes gut health, inflammation, digestion quality, and microbiome diversity through a structured assessment.

Core features for version 1:

1 User authentication

- signup

- login

- password reset

2 User profile

Collect:

- age

- gender

- height

- weight

- activity level

3 Assessment engine

Users complete a multi-step gut health questionnaire.

4 Scoring engine

Generate gut health scores based on answers.

5 Dashboard

Users can see their gut scores and recommendations.

Design style:

- clean wellness aesthetic

- minimal

- calming colors (white, green, beige)

- modern health-tech look

Make it responsive for desktop and mobile.
